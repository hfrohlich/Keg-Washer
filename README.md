# Controle de ciclos para lavadora de barril com Arduino
Previstos ciclos de:
* expurga
* enxágue
* limpeza (soda)
* sanitização (ác. peracético)
* pressurização (CO<sub>2</sub>)
Hardware:
* Bomba sanitária 3/4cv ligada ao bocal de entrada de barril;
* Válvula de entrada de água da rede para a bomba;
* Válvula de entrada de soda do reservatório para a bomba;
* Válvula de entrada de ác. peracético para a bomba;
* Válvula de entrada de CO<sub>2</sub> para o bocal do barril;
* Válvula de expurga do bocal de retorno do barril para o esgoto;
* Válvula de retorno de soda do bocal de retorno do barril para o reservatório;
* Válvula de retorno de ác. peracético do bocal de retorno do barril para o reservatório;
* Display LCD com botões;
* Buzzer.
Abortado por não ter disponíveis válvulas elétricas que permitam bloqueio de fluxo nos dois sentidos (as solenóides disponíveis só bloqueavam em um sentido). Mantida operação manual.
Última atualização: 2015.
